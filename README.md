Projeto CSS

Repositório contendo exercícios e exemplos práticos para o estudo de CSS3.

Sobre o Repositório

Este projeto reúne demonstrações práticas de estilização web, focando em conceitos fundamentais do CSS3, tais como:

Seletores e especificidade

Modelo de caixas (Box Model)

Posicionamento e layout

Estilização de textos, cores e elementos visuais

Tecnologias Utilizadas

HTML5: Estrutura básica das páginas de exemplo.

CSS3: Estilização e formatação visual dos conteúdos.
