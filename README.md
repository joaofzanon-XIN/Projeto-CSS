🎨 Projeto CSS

Repositório com exercícios e exemplos práticos para o estudo de CSS3, aplicados a páginas simples em HTML5.

🎯 Objetivo

Praticar os conceitos fundamentais de estilização web, mostrando como o CSS3 controla a aparência, o espaçamento e a disposição dos elementos de uma página.

✨ Funcionalidades
Páginas de exemplo para testar os estilos:
Início (index.html)
Sobre (sobre.html)
Contato (contato.html)
Demonstrações práticas de:
Seletores e especificidade: como o CSS escolhe qual regra aplicar.
Modelo de caixas (Box Model): margens, bordas, preenchimento e conteúdo.
Posicionamento e layout: organização dos elementos na página.
Estilização de textos, cores e elementos visuais.
Estilos separados do conteúdo, em uma pasta própria.
🛠️ Tecnologias utilizadas
Tecnologia	Uso no projeto
HTML5	Estrutura básica das páginas de exemplo
CSS3	Estilização e formatação visual dos conteúdos
Git e GitHub	Versionamento e hospedagem do código

Funcionamento do Box Model.
Posicionamento de elementos e construção de layouts.
Boas práticas para organizar arquivos de estilo.
